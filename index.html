什么是数字员工

不是 AI 工具，
是能干活的员工

数字员工是围绕具体岗位和场景构建的完整 AI 能力集合。每个数字员工包含业务技能、业务连接器、场景工作流、日常任务和定时任务，能够像真实员工一样持续为企业创造价值。

岗位级能力封装

按产品经理、客服、运营、销售等真实岗位设计，不是泛泛的 AI 工具

场景化工作流

每个工作流服务一个明确业务场景，如竞品日报、会议纪要、内容发布

安全可控

明确的能力边界、权限声明、Mock 测试，不碰真实密钥和客户数据

快速开始

三步拥有你的数字员工

从发现到运行，只需几分钟

1

发现资产

浏览 awesome-digital-employees-zh 总入口，按 20 个行业分类找到适合你的数字员工资产包。

git clone https://github.com/bangwozuo/digital-employee-examples.git
2

配置运行

按照 README 配置环境变量，运行 Mock 测试验证数字员工能力。每个资产包都有完整的测试用例和示例数据。

pytest skills/ && pytest connectors/
3

导入平台

通过 package.yaml 和 employee.yaml 将数字员工导入帮我做平台，启用定时任务，让数字员工开始为你工作。

# 平台自动识别 package.yaml # 一键导入 → 配置 → 运行
